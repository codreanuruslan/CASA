# Доступность и UX

## Реализовано

- `prefers-reduced-motion` уменьшает число частиц и отключает scroll-in анимации;
- мобильное меню обновляет `aria-expanded` и `aria-hidden`;
- `Escape` закрывает мобильное меню;
- цена использует live region в HTML;
- кнопка копирования временно меняет `aria-label`;
- внешние ссылки устава используют `rel="noopener"`.

## Правила изменений

1. Не удаляйте ARIA-атрибуты при редизайне меню.
2. Сохраняйте текстовые статусы swap: цвет не должен быть единственным признаком ошибки.
3. Для новых анимаций проверяйте `reduceMotion`.
4. Не заменяйте реальные `button` и `form` на кликабельные `div`.
5. После изменения DOM проверяйте keyboard navigation и focus order.

## Рекомендуемые проверки

```text
Tab / Shift+Tab      обход интерактивных элементов
Enter / Space        активация кнопок
Escape               закрытие меню
Reduced motion       отсутствие непрерывных анимаций
Screen reader        понятные статусы цены, кошелька и swap
```
